# CyberCigales
Plateforme en ligne ludique pour but d'initier des lycéennes à la cybersécurité

## Description
CyberCigales est un site web éducatif sous forme d’escape game visant à initier
les lycéennes à la cybersécurité et à l’informatique de manière ludique.

## Fonctionnalités
- Jeux type escape game
- Modules de formation intégrés
- Mini-Jeux d'entrainnement et servant à comprendre les formation
- Progression par niveaux
- Interface web responsive

## Technologies
- PHP 
- HTML / CSS / JavaScript
- MySQL
- Git / GitHub
