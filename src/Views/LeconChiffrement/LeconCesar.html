Leçon : Chiffrement de César

Découvre le fonctionnement du chiffrement de César à travers théorie, histoire et exemples pratiques — avec un style cyber-néon.

1) Origine historique

Jules César utilisait ce système pour envoyer des messages codés à ses généraux : chaque lettre était décalée d’un nombre fixe, souvent k = 3.

Exemple : « RENDEZ-VOUS DEMAIN » devient « UHQGHC-YRXV GHPDLQ » pour k = 3.

2) Principe mathématique

Chaque lettre est remplacée par la lettre décalée de k positions dans l’alphabet :

C = (P + k) mod 26

Pour déchiffrer :

P = (C - k) mod 26

où P est la position de la lettre claire, C celle de la lettre chiffrée.

3) Implémentation en pseudo-code

// Entrées : texte, clé k
pour chaque caractère ch dans texte :
  si ch est une lettre :
    pos = ord(ch) - ord('A')
    pos2 = (pos + k) % 26
    résultat += chr(ord('A') + pos2)
  sinon :
    résultat += ch

4) Cryptanalyse

Le chiffrement de César conserve les fréquences des lettres. Cette propriété permet une attaque par analyse de fréquence.

Étapes :
  1. Mesurer la fréquence des lettres du texte chiffré.
  2. Comparer avec la distribution normale du français.
  3. En déduire la clé probable k.
A: 9.4%
B: 1.0%
C: 2.6%

5) Exercices

  1. Chiffre « HELLO » avec k = 3 → « KHOOR ».
  2. Déchiffre « FRZDUG » avec k = 3.
  3. Teste tous les k possibles pour casser le message « ERQMRXU ».

6) Variantes

  • ROT13 — décalage de 13, auto-inverse.
  • Vigenère — clé répétée, polyalphabétique.
  • Vernam — clé aléatoire, sécurité parfaite.
