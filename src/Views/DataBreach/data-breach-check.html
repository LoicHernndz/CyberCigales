À propos de ces fuites

Ces fuites de données sont particulières car l'algorithme de décodage utilisé pour protéger les mots de passe a été divulgué ou reverse-engineered. Cela signifie que les attaquants ont pu décrypter une grande partie des données volées.

Exemples de fuites avec algorithmes divulgués :

  • LinkedIn 2012 : SHA-1 non salé - 90% des mots de passe décryptés
  • Adobe 2013 : Chiffrement réversible (3DES) - algorithme publié sur forums
  • MySpace 2016 : SHA-1 avec salt faible - reverse-engineered
  • CyberCigales Internal 2024 : César + Vigenère - commit accidentel dans dépôt public
