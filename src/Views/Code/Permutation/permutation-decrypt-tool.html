lock_open Outil de Décryptage par Permutation

Cet outil vous aide à décrypter un message chiffré par permutation en réorganisant les colonnes visuellement. Entrez le texte chiffré et le nombre de colonnes, puis déplacez les colonnes pour trouver le message original !

menu_book Comment ça fonctionne ?

1. Le chiffrement par permutation organise le texte en colonnes selon une clé.

2. Pour décrypter sans la clé, il faut tester différentes combinaisons de colonnes (attaque brute force).

3. Glissez-déposez les colonnes pour réorganiser le texte jusqu'à trouver quelque chose qui a du sens !
