lock_open Décryptage par Permutation

Réorganisez les colonnes visuellement pour retrouver le message original

Comment ça fonctionne ?

1. Le chiffrement par permutation organise le texte en colonnes selon une clé.

2. Pour décrypter sans la clé, il faut tester différentes combinaisons de colonnes (attaque brute force).

3. Glissez-déposez les colonnes pour réorganiser le texte jusqu'à trouver quelque chose qui a du sens !
