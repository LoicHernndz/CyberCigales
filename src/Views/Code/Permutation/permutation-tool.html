Permutation

Comment ça marche ?
▼

Le chiffrement par permutation (ou transposition) réorganise les lettres d'un message en les plaçant dans une grille, puis en les lisant dans un ordre différent défini par une clé.

Exemple de chiffrement :

1. Message : BONJOUR
2. Clé : CLE
3. On écrit le message sous la clé :
C L E
B O N
J O U
R _ _
4. On classe la clé par ordre alphabétique :
C(0) E(1) L(2)
5. On lit les colonnes dans cet ordre :
Colonne C : B J R
Colonne E : N U _
Colonne L : O O _
Résultat : bjrnu_oo_

Exemple de déchiffrement :

1. Message chiffré : bjrnu_oo_
2. Clé : CLE
3. On reconstitue les colonnes dans l'ordre de la clé classée :
C(0) : bjr
E(1) : nu_
L(2) : oo_
4. On replace les colonnes selon la clé d'origine :
C L E
B O N
J O U
R _ _
5. On lit ligne par ligne :
Résultat : BONJOUR
