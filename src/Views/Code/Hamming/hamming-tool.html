Carre de Hamming

Trouvez le bit errone dans le carre 3x3

{{{FLASH}}}

Le carre de Hamming est un code correcteur d'erreur. Un bit a ete inverse dans ce carre.

Cliquez sur le bit que vous pensez etre errone.

{{{SQUARE_HTML}}}

Comment trouver l'erreur ?

  • Verifiez la parite de chaque ligne
  • Verifiez la parite de chaque colonne
  • L'intersection des lignes/colonnes incorrectes indique l'erreur
