📖 Guide de la cryptographie

🔄 Chiffrement de César

Méthode utilisée par Jules César. Chaque lettre est remplacée par une autre lettre située à une position fixe dans l'alphabet.

Exemple : Avec un décalage de 3, "ABC" devient "DEF"

🔀 Chiffrement Atbash

L'alphabet est inversé : A↔Z, B↔Y, C↔X, etc. Très ancien, utilisé dans la Bible hébraïque.

Exemple : "ABC" devient "ZYX"

↩️ Chiffrement par inversion

Le texte est simplement écrit à l'envers, mot par mot ou en entier.

Exemple : "BONJOUR" devient "RUOJNOB"

🔢 ROT13

Variante du César avec un décalage fixe de 13. Appliqué deux fois, il redonne le texte original.

Exemple : "ABC" devient "NOP"

📊 Analyse de fréquences

En français, les lettres les plus fréquentes sont E, A, S, I, N, T, R... Cela peut aider à identifier le type de chiffrement.

💡 Conseils

  • Observe la structure du message (espaces, ponctuation)
  • Essaie différents décalages pour le César
  • Utilise l'analyse de fréquences pour repérer les patterns
  • Les indices sont là pour t'aider, n'hésite pas !
