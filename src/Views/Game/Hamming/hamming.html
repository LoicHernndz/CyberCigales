Regles du carre de Hamming

Pour trouver le bit errone :

  1. Compte le nombre de "1" dans chaque ligne
  2. Compte le nombre de "1" dans chaque colonne
  3. Si le total de "1" est pair = ✅ correct
  4. Si le total de "1" est impair = ❌ erreur sur cette ligne/colonne
  5. L'intersection de la ligne et de la colonne incorrectes indique le bit errone !
