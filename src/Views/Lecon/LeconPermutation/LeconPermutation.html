Code de Permutation

Découvre le chiffrement par permutation : réarrangement des lettres pour coder un message.

1) Principe

Le code de permutation consiste à réordonner les lettres d’un message selon une permutation fixe ou une clé spécifique.

Exemple : Texte « ABCD » avec permutation [3,1,4,2] → « BDAC ».

2) Mathématique

Si P est le texte clair et π la permutation, alors :

C_i = P_{π(i)}

Pour déchiffrer, il faut appliquer l’inverse de la permutation :

P_i = C_{π^{-1}(i)}

3) Implémentation

// Entrées : texte, permutation π
résultat = ""
pour i de 0 à len(texte)-1 :
  résultat += texte[π[i]]

4) Cryptanalyse

Le texte chiffré contient les mêmes lettres que le texte clair (anagramme). Les permutations simples sont vulnérables à la recherche exhaustive.

Stratégie :
  1. Analyser les lettres répétées.
  2. Essayer toutes les permutations possibles pour trouver le texte clair.

5) Exercices

  1. Applique la permutation [2,3,1] au texte « CAT ».
  2. Déchiffre « BADC » avec permutation [2,4,1,3].
  3. Teste une permutation de 5 lettres pour coder « HELLO ».
