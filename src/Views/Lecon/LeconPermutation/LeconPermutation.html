Le chiffrement par permutation

Changer l'ordre des lettres à l'aide d'un mot-clé

1. Principe du chiffrement par permutation

Le chiffrement par permutation consiste à changer l'ordre des lettres d'un message.

  • Les lettres ne sont pas modifiées,
  • seule leur position change,
  • l'ordre est déterminé par une clé, ici un mot.

2. La clé : un mot

Dans ce type de chiffrement :

  • la clé est un mot-clé,
  • ce mot est transformé en permutation numérique,
  • cette permutation est ensuite utilisée pour réorganiser les lettres.

3. Transformer un mot en permutation

Mot-clé : CLE

Étape 1 : classer les lettres par ordre alphabétique

Lettre C L E
Ordre alphabétique C E L
Rang 1 2 3

Étape 2 : attribuer à chaque lettre son rang

Lettre du mot C L E
Rang 1 3 2

Clé de permutation obtenue : 1 – 3 – 2

4. Exemple de chiffrement

Message clair : BON

Clé (mot) : CLE

Permutation : 1 – 3 – 2

Chiffrement pas à pas

Position 1 2 3
Lettre B O N
Nouvelle position 1 3 2
Résultat B N O

Message chiffré : BNO

5. Exemple de déchiffrement

Message chiffré : BNO

Clé : CLE

On utilise la même permutation pour remettre les lettres dans l'ordre.

Résultat : BON

6. Pourquoi ce chiffrement est limité ?

Limites

  • Les lettres restent les mêmes → analyse par fréquence possible
  • Clé courte → facile à deviner
  • Peu sécurisé seul

Il est souvent combiné avec d'autres méthodes.
