Chiffrement de Vigenère

Le chiffrement polyalphabétique "indéchiffrable" pendant des siècles.

1) Origine historique

Inventé au XVIe siècle, ce chiffrement améliore le César en utilisant une clé répétée pour décaler les lettres selon plusieurs alphabets.

Exemple : Texte « BONJOUR » avec clé « CLE » → « DQPLQVS ».

2) Principe mathématique

Chaque lettre du texte clair est décalée selon la lettre correspondante de la clé :

C_i = (P_i + K_i) mod 26

Pour déchiffrer :

P_i = (C_i - K_i) mod 26

3) Implémentation

// Entrées : texte, clé
texte = texte.upper()
clé = clé.upper()
résultat = ""
for i de 0 à len(texte)-1 :
  si texte[i] est une lettre :
    P = ord(texte[i]) - ord('A')
    K = ord(clé[i % len(clé)]) - ord('A')
    C = (P + K) % 26
    résultat += chr(ord('A') + C)
  sinon :
    résultat += texte[i]

4) Cryptanalyse

La répétition de la clé crée des motifs détectables (Attaque de Kasiski).

Méthode :
  1. Identifier les répétitions de séquences.
  2. Mesurer les distances pour déduire la longueur de la clé.
  3. Appliquer l'analyse de fréquence sur les sous-textes.

5) Exercices

  1. Chiffre « SALUT » avec clé « ABC ».
  2. Déchiffre « DQPLQVS » avec clé « CLE ».
  3. Teste une clé courte pour deviner un message chiffré « WFSJX ».
