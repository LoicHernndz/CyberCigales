Le chiffrement de Vigenère

Comprendre un chiffrement simple et malin

1. À quoi sert le chiffrement ?

Le chiffrement permet de rendre un message illisible pour toute personne qui ne possède pas la bonne information pour le comprendre.

Il est utilisé pour :

  • protéger des messages,
  • sécuriser des données,
  • éviter que des informations confidentielles soient lues par des personnes non autorisées.

Le chiffrement de Vigenère est un chiffrement par substitution, c'est-à-dire que chaque lettre du message est remplacée par une autre lettre.

2. Le principe du chiffrement de Vigenère

Le chiffrement de Vigenère utilise :

  • un message clair (le message à protéger),
  • une clé secrète (un mot),
  • un décalage différent pour chaque lettre, grâce à la clé.

À noter : Contrairement au chiffrement de César (qui utilise toujours le même décalage), Vigenère change le décalage à chaque lettre, ce qui le rend plus sécurisé.

3. Comment fonctionne la clé ?

La clé est un mot que l'on répète autant de fois que nécessaire pour couvrir tout le message.

Exemple :

Message : BONJOUR

Clé : CLE

On répète la clé : CLECLEC

Chaque lettre de la clé indique combien on décale la lettre du message.

4. Associer les lettres à des nombres

Pour chiffrer, on associe chaque lettre à un nombre :

Lettre A B C D E ... Z
Nombre 0 1 2 3 4 ... 25

5. Chiffrement étape par étape

Exemple complet

Message : BONJOUR

Clé répétée : CLECLEC

Message B O N J O U R
Valeur 1 14 13 9 14 20 17
Clé C L E C L E C
Valeur 2 11 4 2 11 4 2
Calcul 1+2 14+11 13+4 9+2 14+11 20+4 17+2
Résultat D Z R L Z Y T

Message chiffré : DZR LZYT

6. Déchiffrer un message de Vigenère

Exemple de déchiffrement du chiffrement de Vigenère

Message chiffré : DZR LZYT

Clé : CLE

1. Répéter la clé

On répète la clé pour qu'elle ait la même longueur que le message chiffré (sans les espaces) :

Message chiffré : D Z R L Z Y T
Clé répétée : C L E C L E C

2. Associer les lettres à des nombres

Lettre A B C D E ... Z
Nombre 0 1 2 3 4 ... 25

3. Déchiffrement étape par étape

Cette fois, on fait l'opération inverse : lettre chiffrée − lettre de la clé

Chiffré D Z R L Z Y T
Valeur 3 25 17 11 25 24 19
Clé C L E C L E C
Valeur 2 11 4 2 11 4 2
Calcul 3−2 25−11 17−4 11−2 25−11 24−4 19−2
Résultat B O N J O U R

4. Message déchiffré

Message clair : BONJOUR

Astuce importante

Si le résultat du calcul est négatif, on ajoute 26.

Exemple :

  • 2 − 5 = −3
  • −3 + 26 = 23 → X

À retenir

  • Chiffrer → on additionne
  • Déchiffrer → on soustrait

7. Pourquoi Vigenère est plus sécurisé ?

Avantages :

  • le décalage change à chaque lettre,
  • plus résistant que le chiffrement de César,
  • difficile à casser sans la clé.

Limites :

  • si la clé est courte et répétée souvent, elle peut être retrouvée,
  • aujourd'hui, il n'est plus assez sécurisé pour protéger des données sensibles.
